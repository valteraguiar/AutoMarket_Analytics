🚗 AutoMarket Analytics

Análise do Mercado Brasileiro de Veículos

Projeto de Data Analytics desenvolvido para analisar aproximadamente 599 mil registros de veículos, utilizando Python, SQL, SQLite e Tableau Public.

O projeto simula um cenário de análise de mercado para identificar padrões de preços, participação das marcas, características dos veículos e oportunidades de geração de insights para tomada de decisão.

---

🎯 Objetivo

Analisar o comportamento do mercado de veículos a partir de dados da Tabela FIPE, transformando dados brutos em informações relevantes para apoiar análises de negócio.

As principais perguntas analisadas foram:

- Quais marcas apresentam os maiores preços médios?
- Quais marcas possuem maior representatividade na base?
- Como os preços variam de acordo com combustível?
- Existe diferença relevante entre veículos manuais e automáticos?
- Como o preço médio se comporta conforme o ano do modelo?
- Quais modelos apresentam os maiores preços médios?
- Qual a relação entre motorização e preço?

---

💡 Principais insights

A análise inicial identificou forte concentração de registros em marcas como Volkswagen, Chevrolet e Fiat.

No extremo oposto, marcas premium e de luxo apresentaram os maiores preços médios da base, com destaque para Rolls-Royce, McLaren e Ferrari.

As análises de combustível, câmbio, motorização e ano do modelo foram utilizadas para identificar possíveis relações entre características dos veículos e seus respectivos preços médios.

«Os insights apresentados no dashboard devem ser interpretados considerando o período e a composição da base analisada.»
